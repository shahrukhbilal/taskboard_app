## 🌟 Overview

A **modern taskboard / Kanban-style task management application** built with **Next.js** and **Tailwind CSS**.  
Users can create boards, add tasks, move them between stages, and organize work visually — similar to Trello.  

Live frontend and backend deployed on **Vercel**.

---

## ✨ Key Features

- 🧭 **Kanban Task Board** – Move tasks across columns like *To Do*, *In Progress*, and *Done*  
- 👀 **View & Manage Tasks** – Users can view all their tasks and manage them easily from the board  
- ➕ **Add / Edit / Delete Tasks** – Create new tasks, update existing ones, or remove completed tasks  
- 🔁 **Drag & Drop Support** – Rearrange tasks and lists smoothly using drag and drop (if implemented)  
- 📁 **Multiple Boards** – Organize work using separate boards for different projects or workflows (if supported)  
- 🧑‍💻 **Responsive UI** – Fully responsive design that works on desktop, tablet, and mobile devices  

### 🔐 Optional / Future Enhancements
- User authentication & profiles  
- Task deadlines & due dates  
- Task filtering & search  
- Notifications & reminder
